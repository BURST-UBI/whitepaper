# BURST Whitepaper

Published website and illustrations explaining BURST, its currency and protocol.
Read it at [brst.cc](https://brst.cc).

The repository root contains the exported static site. Preview it locally with:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open `http://localhost:8000`.

Maintained documentation lives in the
[protocol repository](https://github.com/BURST-UBI/protocol/tree/main/docs).
Edit those Markdown sources for protocol documentation; this static export is
not automatically synchronized with them.
